# 完整工程与 Dynamic V4 验证

在验证上下游耦合、完整画布、动态时间序列、持续运行进程或离线整图时读取。

## 本地完整工程

服务器网页只负责画布、模板实例值和物性数据；源码验收由本机 Python 进程加载本地调度库
和 `domain/`。使用测试契约中确认的真实工程入口：

```powershell
$env:PYTHONPATH='.'
uv run python -B <实际工程运行文件>
```

运行前按入口签名核对 `host`、`pro`、计算模式、`pk`、`special_pk` 等参数。完整工程至少
确认目标 `.py` 的 `module.__file__`、实际执行顺序、上下游边界、衡算、消费者和退出状态。

若动态入口持续等待退出信号，记录本次启动 PID，采用受控停止，只清理本次进程。工具调用
中断后立即检查本次启动的 `uv/python` 子进程，不影响其他项目或服务。

## Dynamic V4 入口与时间步

1. 从真实模板 `startFun` 和控制器调用点确认角色：普通主进程设备通常调用 `Run`，动态
   子进程调用 `RunDynamic`，特殊 ODE 模板才调用 `RunOde(ts, dt)`。
2. 当前 V4 主、子控制器的小写 `run()` 是控制器方法，不是设备入口；V4 不自动追加
   `DRun`。直接调用 `DRun` 的历史测试只能作为 V1 证据。
3. 普通设备单步从 `self.Data.PGV["DT"]` 获取有效步长；改变该项目配置后，时间序列应按
   新步长变化。外部传入的任意 `dt` 不能替代这个所有权规则。
4. 一次真实入口调用只推进一个 `DT`，不能由多个公开入口或辅助方法重复积分；事件分段
   时各子段时长之和必须等于本步 `DT`。
5. 普通常微分动态模型默认验证经典 RK4 的 `k1/k2/k3/k4`、状态 shape、单位和时间层级，
   并与解析解、可靠参考结果或步长减半结果比较。特殊方法须核对已确认理由及对应精度、
   稳定性验证。

## Dynamic V4 专项检查

- 普通动态设备没有已核实返回消费者时，成功路径不返回业务信息，也不定义 `result` 或
  空结果占位。
- 连续采集多个时间步，检查状态方向、连续性、守恒残差、边界工况和一拍时序。
- 实时展示从真实同名实例属性观测，下游边界从实际出口节点观测；没有消费者的通道记为
  不适用。
- `Data.PGV["DT"]` 或候选状态无效时，本步不推进，上一已提交状态和出口保持一致，不
  留下部分修改，也不为了保护边界而构造错误返回。
- 覆盖干/满设备、容差内外、候选状态保护、出口发布回滚和恢复后继续推进。
- 动态状态观测使用既有 logger 或测试入口外部采集，记录时间、真实设备入口、关键状态
  和衡算输入/输出；验证完成后删除临时代码并回归。

## 通用业务检查

1. 先列出模板、控制器和所属族 Skill 证明的消费者；不适用通道不补占位。
2. 需要 `(bool, dict)` 的入口核对成功和失败结构；需要 `result` 时才检查外层结构、中文键
   和 `unitType`。不消费返回值的族核对状态和错误传播。
3. 模板要求展示、落库或引用的同名属性在运行后具有正确值；出口节点按族契约写全。
4. 核对所选质量、组分、能量、动量或相平衡，记录闭合误差。
5. 同输入可复现；缓存或暖启动在输入变化后不复用失效状态。
6. 按 `cslab-module-contract` 覆盖有限值、范围、组成、数学定义域、守恒、求解器、状态
   提交和矩阵局部保护。
7. 可恢复保护不抛异常或发送错误反馈；无法得到受保护新值时保留上一有效值或已提交状态。
8. 源码注释和实际实现一致，无临时 `print`、未定义分支或已否决方案描述。

## 离线整图

仅在需要多模块耦合或执行顺序验证时使用项目现有 `chemical-scheduler` 本地入口。若当前
版本的 `runServerLocal` 从 `data/calculateDependData/<项目>/` 读取 YAML，则先按实际
接口导出 `CalculateData` 和 `chemicalData`，并核对其 etcd 等服务依赖。实现可能随项目
版本变化，运行前必须读取当前源码，不能把此历史形式当固定入口。单模块优先使用最小脚本。

## 结束与记录

- 只停止本次测试启动的 PID，并检查其子进程；不批量终止其他 Python 或项目服务。
- 删除临时状态观测和测试性输出，恢复要求恢复的同名二进制隔离文件，再做最终回归。
- 记录实际命令、加载路径、输入工况、结果、误差、进程清理、未覆盖分支和遗留风险。
- 模板槽位、`startFun` 和上线触发属于部署登记，按 `cslab-modulet-api` 执行；本 Skill
  不重复定义模板写接口或权限规则。
